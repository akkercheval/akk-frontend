# Gypsa All-Fours Pose — Targeted Correction Prompts

**Purpose:** Fix the all-fours base render **one edit at a time**. ChatGPT's image
editor is most reliable when asked for a single, isolated change per prompt, so
each section below is a standalone edit with its own paste-ready instruction and
its own recommended attachments.

**Base image to start from:** `ChatGPT Image Sep 23, 2026, 10_11_45 PM.png` (the
all-fours attempt with the backpack removed — good body, tail, and proportions).

**How to use this document:**
- Do the edits **in the order below** and **feed each edit's output into the next
  edit** (so fixes accumulate). The order puts the cheap, low-risk fixes first and
  the riskier structural add (backpack) last.
- For every edit, use the standing rule: *"Make only the change I request. Do not
  alter anything else in the image — keep the pose, proportions, colors, tail,
  and line style exactly the same."*
- Attach only the references listed for that specific edit. Fewer, targeted
  references reduce the chance the editor "helpfully" changes other things.

**What is already correct (do NOT change):** the all-fours pose, the ~1.70H back
length and overall proportions, the gray-dominant fur, and the tail (big S-curve
rooted at the base of the spine). These validated on this render — protect them.
