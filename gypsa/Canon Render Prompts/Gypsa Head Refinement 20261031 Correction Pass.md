## How to use this sheet

1. **Work one step at a time, in order.** Shape fixes come before color fixes so recolors land on the final shapes. Do **not** paste all steps at once.
2. For each step: start a fresh ChatGPT turn, **attach the latest accepted image** (Step 1 attaches the original; every later step attaches the output you accepted from the previous step), paste that step's prompt, generate.
3. After each step, run the **Verify** checklist. If any previously-accepted feature broke (ChatGPT edits can drift untouched areas), **reject that output**, re-attach the prior accepted image, and re-run with the "repair" note appended (see *If a step regresses* below). Do not carry a regressed image forward.
4. Keep a flat, clean, no-gradient look throughout. Reject any output that adds gloss, airbrushing, rim light, or background.
5. **Reading convention:** left-facing three-quarter. **Near** = Gypsa's anatomical left = **image-right**. **Far** = anatomical right = **image-left**.

## If a step regresses a previously-accepted feature

ChatGPT sometimes alters untouched areas. If the Verify list flags a regression:

1. **Reject** that output. Do not carry it forward.
2. Re-attach the **prior accepted** image.
3. Re-run the same step prompt with this line appended:
   > IMPORTANT: In your last attempt you also changed [name the feature, e.g. "the crown spikes" / "the eye size"]. Do NOT touch that feature this time — leave it exactly as in the attached image. Apply only the change described above.
4. If a step repeatedly fails, split it (e.g. do the near ear and far ear in separate turns for Step 1) rather than forcing the whole change at once.
