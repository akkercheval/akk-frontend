# Class Comparison Overview

Twelve classes is a lot to choose from, so here's a side-by-side look to help
you narrow it down — whether you're brand new to the game or just new to a
class. For the full write-up on any class, head back to the
[Class Guides](/lotro/classes) page and pick its button.

## How to Read This Table

- **Availability** — whether the class is **Free** (available to every account)
  or **Premium** (a class you buy separately).
- **Common Roles** — the roles each class most often fills in groups. Most
  classes can do more than one; this is where they're usually slotted.
- **Beginner Friendliness** — how approachable the class is while you're still
  learning. This is about the *learning curve*, not how powerful the class is.

Beginner friendliness uses three simple tiers:

- 🟢 **Beginner-friendly** — a good place to start.
- 🟡 **Some experience helps** — learnable, but smoother once you know the game.
- 🔴 **Advanced** — challenging; best saved for when you're comfortable.

## Quick Picks for New Players

If you're just getting started and want something approachable, these are the
easiest on-ramps:

- **Hunter** — straightforward ranged damage; a classic first class.
- **Minstrel** — a flexible healer that can also deal damage.
- **Guardian** — a sturdy, forgiving tank-and-damage class.
- **Champion** — simple, fun melee damage.

The **Brawler** is also fairly easy to learn if you don't mind that it's a
premium (purchased) class.
